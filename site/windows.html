Walked before you

This guide was walked by Koketso, the first person outside our own machines to run God Code on Windows. Every hurdle below is one he actually hit, and every fix is one that worked. If he can do it, you can do it.

What you need

  • Windows 10 or 11.
  • Python 3.10 or newer.
  • VS Code, with the God Code extension.

Step 1: Install Python

Get it from python.org. On the very first install screen, tick the box that says Add python.exe to PATH before you click Install. That one tick prevents half the trouble below.

Check it worked. Open PowerShell and run:

python --version

You should see a version number like Python 3.12.

Step 2: Upgrade pip

In the same PowerShell window, run:

python -m pip install --upgrade pip

This makes sure your installer is fresh. Koketso's first hurdle was an old pip, and this cleared it.

Step 3: Install God Code

Now install the language itself:

python -m pip install --user godcode-engine

Note the name carefully: it is godcode-engine, one word with a hyphen. An early version of our own instructions said pip install godcode, which does not exist, and that cost Koketso a good twenty minutes. Learn from his patience.

Step 4: The PATH hurdle

After installing, you may see a yellow warning saying the Scripts folder is not on PATH. That means Windows does not know where to find the godcode command yet. Fix it like this:

  1. Press the Windows key, type environment variables, and open it.
  2. Click Environment Variables. Under your user variables, select Path and click Edit.
  3. Add the folder from the warning. It looks like this:
    C:\Users\YOURNAME\AppData\Roaming\Python\Python312\Scripts
    (yours will show your own username and Python version).
  4. Click OK on every window.

Then close your terminal completely and open a fresh one. This is the step everyone forgets. The old window does not know about the change. In the fresh window, run:

godcode --help

If you see the help text, you are set.

Step 5: Install the VS Code extension

Open VS Code, press Ctrl+Shift+X, search for God Code, and click Install. The extension finds your interpreter on its own, on Windows too.

Get the extension

Step 6: Run your first creation

Create a file called hello.god and write:

BEGIN CREATION DECLARE seeker AS "world" BREATHE life INTO seeker REVEAL("Hello, " + seeker) ASCEND END CREATION

Press Ctrl+Alt+R and watch it ascend.

If something still will not move

  • "No matching distribution found" when installing: you typed the wrong package name. It is godcode-engine.
  • "God Code interpreter not found" in VS Code: make sure the extension is updated to the latest, then close VS Code completely and open it again.
  • Nothing changed after a fix: close the terminal and VS Code fully and reopen them. Windows only picks up new settings in fresh windows. This one caught Koketso twice.
  • Still stuck: come to our Discord and ask. You will be helped by people who have walked this exact path.
