The Seven Seals seven_seals.god

Every number from 1 to 35 is judged. Multiples of 7 are sealed, 35 receives the seal of seals.

FOR n IN RANGE(1, 36)
  IF n % 35 IS 0 THEN
    REVEAL("seal of seals")
  ELSE
    IF n % 7 IS 0 THEN
      REVEAL("seal")
    ELSE
      REVEAL(n)
    ENDIF
  ENDIF
ENDFOR

Install the engine

  1. Clone the scrolls 
    git clone https://github.com/godcodeengine/Godcode-engine
cd Godcode-engine
  2. Receive the command (Python 3.10+) 
    pip install -e .
  3. Speak your first creation 
    godcode run sample.godcode
godcode repl   # live mode

Prefer an editor? The VS Code extension adds highlighting, snippets, and one-key running. No install at all? The playground runs entirely in your browser.
