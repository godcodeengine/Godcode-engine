The news

God Code is now on the Visual Studio Marketplace. Install the extension and write your creations without ever leaving your editor. No cloning, no configuration. Search, install, begin.

Install God Code for VS Code

Free forever. Open source under the Apache 2.0 license.

What you get

  • Full syntax highlighting for .god files. Your creations light up like scripture.
  • 27 snippets: creation, intent, consult, anchor, and blocks in Setswana and isiZulu.
  • Run the open file with Ctrl+Alt+R and watch it ascend.
  • Smart indentation and comment support, built for the language as it is today.

Install in four steps

  1. Install the language itself: open a terminal and run pip install godcode-engine (needs Python 3.10 or newer).
  2. Open VS Code and click the Extensions tab, or press Ctrl+Shift+X.
  3. Search for God Code.
  4. Click Install. Then open a .god file and write.

Try this first creation

BEGIN CREATION DECLARE seeker AS "world" BREATHE life INTO seeker REVEAL("Hello, " + seeker) ASCEND END CREATION

Save it as hello.god and press Ctrl+Alt+R.

Build it with us

God Code is being built in the open by all of us. During Hacktoberfest, developers from outside our circle started contributing. One of them, Atharv, gave the language a brand new word: REPEAT. It is merged, it is live, and it is proof that this movement is real.

If you have ever wanted to help build a programming language, this is your invitation. You do not need to be an expert. Here is what is open right now:

  • Write a market day sales report scroll
  • Add VS Code snippets for the common builtins
  • Refresh the contributing docs folder map
  • Bless Setswana words for ELSE, NOT, FOR, WHILE, ENDFOR and ENDWHILE
  • Add a third tongue in your own mother language

Read the contributing guide, pick an issue, and come say hello in our Discord.
