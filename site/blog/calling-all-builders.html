Calling all builders

An invitation to write the language with us.

October 10, 2026

Home Playground Learn Demos Blog GitHub Discord

God Code is a programming language that reads like scripture, and it is being built in the open by all of us.

During Hacktoberfest, developers from outside our circle started contributing. Atharv gave the language a brand new word: REPEAT. GreedyC refreshed our contributor guide so the next builder finds a clear door. Both are merged, both are live, and they are proof that this movement is real.

Now we are opening the doors wider. If you have ever wanted to help build a programming language, this is your invitation. You do not need to be an expert. Some open tasks are writing example programs, blessing words in your own mother tongue, and improving the docs.

Start here: github.com/godcodeengine/Godcode-engine. Read the contributing guide, pick an issue labeled good first issue, and come say hello in our Discord.

Come and write the language with us.

Alakanani
