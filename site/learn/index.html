✨ 1. What is God Code?

God Code is the first spiritually-inspired programming language — symbolic, intention-driven, and alive. It blends an intent-reading Spirit Engine, divine conditional logic, and a tamper-evident covenant ledger.

✦ the_shape.god
BEGIN CREATION
  DECLARE seeker AS worthy
  IF seeker IS worthy THEN REVEAL("heaven") ELSE REVEAL("test")
  ASCEND
END CREATION

Notice: worthy needs no quotes. In God Code, bare words are symbols. Every unnamed thing is still a named spirit. This is the Symbol Rule, and it is the heart of the language.

🛠️ 2. Your first creation

Open the playground — no install needed — and breathe this in:

✦ my_first.god
BEGIN CREATION
  DECLARE spirit AS humble
  IF spirit IS humble THEN REVEAL("peace") ELSE REVEAL("struggle")
  ASCEND
END CREATION
peace
🕊 Creation ascended in peace.

What just happened, line by line:

LineMeaning
BEGIN CREATIONevery program is a creation — this opens it
DECLARE spirit AS humblebinds the name spirit to the symbol humble
IF … THEN … ELSE …IS tests equality; the truthy branch reveals "peace"
REVEAL("peace")speaks a value aloud
ASCENDends the creation in peace
END CREATIONcloses the creation

Change humble to proud and run it again. Watch the prophecy change. You did that.

📜 4. Decisions, cycles, and rites

Speak with feeling

✦ speak.god
DECLARE name AS "seeker"
DECLARE loaves AS 5
REVEAL("grace upon {name}")
REVEAL("{loaves} loaves feed {loaves * 1000}")
REVEAL("a plain {{ brace }} stays a brace")

Anything in {braces} inside a quoted string is breathed into the words: a name, a sum, a builtin rite like UPPER(name). Double a brace ({{, }}) to write a plain one.

Decide

✦ decide.god
IF heart IS pure THEN

✦ cycle.god

Bless and reuse

✦ rite.god
DEFINE RITE BLESSING(name)

END RITE
REVEAL(BLESSING("seeker"))

Seal a word with a hash

✦ hashes.god — runs in the installed engine
BEGIN CREATION
  REVEAL(SHA256("manna"))
  DECLARE sig AS HMAC("secret", "the covenant stands")
  REVEAL(sig IS HMAC("secret", "the covenant stands"))
  REVEAL(BASE64_DECODE(BASE64_ENCODE("veiled")))
END CREATION

SHA256(x) takes a word's fingerprint: always 64 hex characters, the same word always giving the same fingerprint, and the tiniest change giving a wholly different one. HMAC(key, message) seals a message under a key so only a keeper of the key can verify it. BASE64_ENCODE and BASE64_DECODE veil and unveil words. These four need no import and run the same inside the sandbox, and the hashes scroll (godcode scroll install hashes) wraps them in friendly rites: FINGERPRINT, SIGN, VERIFY_SIGNATURE, VEIL, and UNVEIL.

Everyday tools for words, lists, maps, and numbers

✦ commons.god — runs in the installed engine
BEGIN CREATION
  REVEAL(TRIM("  grace upon grace  "))
  REVEAL(REPLACE("manna, manna", "manna", "bread"))
  REVEAL(REPEAT("Pula! ", 3))
  REVEAL(SORT([3, 1, 2]))
  REVEAL(SUM_OF([1, 2, 3, 4]))
  REVEAL(UNIQUE(["a", "b", "a"]))
  DECLARE census AS JSON_PARSE("{{\"tribes\": 12}}")
  REVEAL(HAS_KEY(census, "tribes"))
  REVEAL(ROUND(2.5))
  REVEAL(SQRT(144))
  REVEAL(POW(2, 10))
END CREATION

Twenty-six small tools that turn everyday work into one line, always present with no import. TRIM, REPLACE, STARTS_WITH, ENDS_WITH, SUBSTRING, CONTAINS, COUNT, and REPEAT shape words. SORT, MIN_OF, MAX_OF, SUM_OF, FIRST, LAST, UNIQUE, and INDEX_OF gather lists (SORT and MERGE always return new values; the old ones are untouched). KEYS, VALUES, HAS_KEY, and MERGE read maps. ABS, ROUND, FLOOR, CEIL, SQRT, and POW weigh numbers. They are pure computation, so they run the same inside the sandbox, and every one answers a misuse with a gentle error instead of a crash.

Shelter a fragile work

✦ shelter.god
TRY
  DECLARE share AS 10 / 0
CATCH
  REVEAL("caught: " + ERROR)
ENDTRY

TRY shelters a fragile work: if it stumbles, the run does not end. Execution moves to CATCH with the plain message bound to ERROR (or a name of your choosing, as in CATCH trouble). BREAK releases a loop at once; CONTINUE turns its wheel to the next turn. The playground speaks them too, with a ready-made "Sheltered by Grace" creation.

Speak Setswana

✦ dumela.god — the first tongue
# tongue: tn
QALA TLHOLEGO
BOLELA leina JAKA "Lefatshe"
SENOLA("Dumela, {leina}.")
FEDISA TLHOLEGO

God Code's heart was born in Botswana, and now its grammar speaks Setswana. Open a scroll with the line # tongue: tn and the keywords cross over: QALA for BEGIN, SENOLA for REVEAL, FA and GONE for IF and THEN, LEKA and TSHWARA for TRY and CATCH. English words still work beside them, so you can cross over one word at a time, and the named tools (SHA256, UPPER, RANGE) keep their names in every tongue. The playground reads the pragma too, and boots a "Dumela (Setswana)" creation ready to run. The full word table lives in docs/TONGUES.md; if you speak Setswana and a word rings wrong, you are its rightful editor. The godcode lsp language server reads the pragma as well: it offers Setswana completions like SENOLA (REVEAL), and hovering a Setswana word shows the English keyword's own notes. The VS Code extension paints Setswana keywords in their colors, and typing qala or fa unfolds a Setswana creation block or conditional.

Speak isiZulu

✦ sawubona.god — the second tongue
# tongue: zu
QALA INDALO
MEMEZELA igama NJENGA "Umhlaba"
VEZA("Sawubona, {igama}.")
QEDA INDALO

The second tongue is isiZulu, spoken across South Africa and beyond. Open a scroll with the line # tongue: zu and the keywords cross over again: QALA for BEGIN, VEZA for REVEAL, UMA and KHONA for IF and THEN, ZAMA and BAMBA for TRY and CATCH. Two-word closers work the same way: QEDA UMA closes an IF, and QEDA ZAMA closes a TRY. The playground reads this pragma too, and boots a "Sawubona (isiZulu)" creation ready to run. The language server offers isiZulu completions like VEZA (REVEAL), and the VS Code extension paints isiZulu keywords and ships starter snippets: type sawubona or uma. The full word table lives in docs/TONGUES.md; if you speak isiZulu and a word rings wrong, you are its rightful editor.

🕊️ 6. Intent & chain

God Code learns to ask why. Name a rite's purpose in plain words, and the Spirit watches over it:

DECLARE INTENT "bring peace to the household" ON evening_blessing

When the rite is invoked, alignment is blessed; drift is counseled gently, never punished. You can also anchor any value's hash on a chain and keep the receipt (ANCHOR(x)), or lay a question before the local oracle (CONSULT("...")). Agents get six MCP-compatible tools via godcode tools and a JSON-RPC bridge via godcode bridge. Try the three creations: intent_demo.god, anchor_demo.god, consult_demo.god.

When the Spirit corrects you

Mistakes are met with kindness, not scorn. Misspell a rite or a name and the heavens suggest the word you meant:

There is no rite named 'BLESSIN'. The heavens do not know it. Did you mean 'BLESSING'? (line 5)
  5 |   INVOKE BLESSIN("seeker")

The command line shows the exact line that stumbled. Read it, take the suggestion, and speak again.
